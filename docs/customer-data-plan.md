# MAYDIN 회원 데이터 계획

회원 데이터를 사업 확장(재구매·등급·가맹 영업·신규 지점·PB 상품)에 활용하기 위해 무엇을 모으고, 어떻게 계산하고, 어디에 보여 줄지 정리한 문서입니다. 기준값은 모두 파트너센터 설정에서 바꿀 수 있게 만듭니다.

## 0. 원칙

- 빼는 것: 상담 주제 분류, 건강 관련 관심사 체크. 관심사는 실제 구매한 상품으로 추론합니다.
- 저장하지 않는 것: 주민등록번호, 카드번호, 비밀번호 원문.
- 연락처(문자 발송·CSV 연락처 열)는 마케팅 수신에 동의한 회원만 활용합니다.
- 일반의약품은 지금처럼 매장 대면 판매만, 포인트 적립·사용 대상에서 제외합니다.

## 1. 회원에게 받는 정보

| 구분 | 항목 |
|---|---|
| 필수 | 이름, 전화번호, 가입 약국 |
| 선택 | 생일(월·일), 출생연도, 성별, 추천인 코드 |
| 자동 기록 | 가입 일시, 회원코드, 가입 경로(어느 QR로 들어왔는지), 추천인 |
| 가족 | 대표 회원 아래 가족 연결 |

전화번호 문자 인증은 문자 발송 서비스 계약 후 보안 작업에서 붙입니다.

## 2. 동의 이력

- 항목: 필수 약관, 개인정보 수집·이용, 마케팅 수신(문자 / 알림톡 각각), 야간(21시~08시) 광고 수신, 제3자 제공. 이메일은 실제 주소를 받지 않으므로 뺐습니다.
- 항목마다 동의·철회 시각, 약관 버전, 경로(QR 가입 / 매장 / 고객 앱)를 기록합니다. 기록은 지우지 않고 쌓습니다.
- 마케팅 동의 후 2년이 되는 회원을 재확인 대상으로 뽑습니다.
- 가입 화면은 항목별 체크, 고객 앱에서 직접 변경, 파트너센터에서 고객별 상태 확인.

## 3. 구매 기록으로 자동 계산하는 회원 지표

금액
- 1회 평균 결제 금액대: 1만 원 미만 / 1~3만 / 3~5만 / 5~10만 / 10만 원 이상
- 월 평균 지출, 누적 순구매 금액(반품 차감), 최고 결제 금액

등급 (기본값, 최근 12개월 순구매 기준)

| 등급 | 기준 | 포인트 추가 적립 |
|---|---|---|
| 일반 | 10만 원 미만 | 기본 적립률 |
| 실버 | 10만 원 이상 | +0.5%p |
| 골드 | 30만 원 이상 | +1%p |
| VIP | 70만 원 이상 | +2%p |

회원 상태
- 신규: 첫 구매 후 30일 이내
- 재방문 없음: 첫 구매 후 다시 사지 않음
- 활성
- 이탈 위험: 평소 구매 간격의 2배가 지나도록 구매 없음
- 휴면: 180일 이상 구매 없음

행동
- 평균 구매 주기, 마지막 구매일, 최근 12개월 구매 횟수
- 선호 채널(매장 / 픽업 / 배송), 주로 오는 요일·시간대, 주 결제수단
- 할인 민감도(할인·포인트를 쓴 구매 비율)
- 선호 카테고리·브랜드 상위 3개
- 다음 구매 예상일(상품 복용 기간 기준)
- 추천으로 데려온 회원 수

## 4. 상품·약국 쪽 데이터

- 상품: 복용·사용 기간(일), 브랜드
- 가입 경로별 QR: 카운터 / 전단 / 제휴처 등 여러 개 발급, 경로별 스캔·가입·첫 구매 수
- 수요 신호: 결과 없는 검색어, 품절 상품 입고 알림 신청, 고객 상품 요청
- 함께 사는 상품: 같은 결제에서 자주 같이 팔리는 조합

## 5. 화면

- 파트너센터 "회원 분석": 요약(활성 회원, 재구매율, 평균 구매 주기, 회원 식별률, 등급·금액대·연령대·성별 분포, 가입 경로별 성과), 필터(등급, 금액대, 상태, 선호 채널, 이번 달 생일, 마케팅 동의, 재구매 예정), CSV, 회원 상세(지표·구매 이력·포인트·동의 이력·가족)
- 파트너센터 설정: 등급 기준·추가 적립률, 이탈·휴면 기준, 생일·추천 혜택
- 매출 리포트: 함께 산 상품, 수요 신호
- POS: 회원 스캔 시 등급·이번 달 생일·이탈 위험 표시, 등급별 적립률 자동 반영
- 고객 앱: 내 등급과 다음 등급까지 남은 금액, 생일·성별 입력, 추천 코드, 동의 관리, 입고 알림 신청
- 본사 관리자: 약국별 성과 리포트(회원 수, 재방문율, 객단가)

## 6. 대표가 정할 것

- 등급 기준 금액과 추가 적립률 (기본값으로 시작)
- 이탈·휴면 기준 (기본값: 평소 간격의 2배, 180일)
- 생일 혜택 (기본값: 생일 달 포인트 2배)
- 추천 보상 (기본값: 추천한 사람·가입한 사람 각 1,000P, 가입자의 첫 구매 후 지급)
- 데이터 소유 구조와 약관: 약국과 MAYDIN 중 누가 개인정보처리자인지 계약으로 정리 (개인정보 전문 변호사 확인 권장)

## 7. 진행 순서

1. 기반: 동의 이력, 선택 정보, 가입 경로별 QR
2. 회원 분석: 지표 계산, 등급제, 회원 분석 화면, CSV
3. 상품 데이터: 복용 기간·브랜드, 다음 구매 예상일, 함께 사는 상품, 수요 신호
4. 현장 반영: POS 등급 표시·등급 적립, 고객 앱 내 등급·동의 관리·입고 알림
5. 확장: 가족 회원, 본사 약국별 성과 리포트

실제 문자·알림톡 발송은 문자 서비스 계약 후 붙이고, 그 전에는 발송 대상 목록과 CSV까지 제공합니다.
